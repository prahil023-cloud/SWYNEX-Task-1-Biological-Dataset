# SWYNEX Task 1 – Biological Dataset Selection

## 1. Dataset Name
Breast Cancer Relapse Free Survival

## 2. Dataset Accession Number
GSE2034

## 3. Database / Source
NCBI Gene Expression Omnibus (GEO)

## 4. Organism
Homo sapiens

## 5. Experiment Type
Expression profiling by array

## 6. Dataset Size
The dataset contains 286 samples.

## 7. Dataset Description
GSE2034 is a publicly available gene-expression dataset related to breast cancer relapse-free survival. It contains gene-expression data from human breast cancer samples along with clinical information related to relapse and follow-up.

## 8. Research Question
Can gene-expression patterns be associated with relapse outcomes in breast cancer patients?

## 9. Potential Use
This dataset can be used for secondary data analysis and bioinformatics research to explore gene-expression patterns associated with breast cancer relapse.

## 10. Data Source
NCBI Gene Expression Omnibus (GEO)

Dataset Link:
https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE2034

## 11. Conclusion
GSE2034 is a publicly available biological dataset that can be used to study the relationship between gene-expression patterns and breast cancer relapse outcomes. It contains 286 samples and associated clinical information that can support bioinformatics analysis.
